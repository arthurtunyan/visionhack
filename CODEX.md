# Codex Project Instructions

## Project context

VisionHack is in its initial setup phase. Do not assume a framework, language, package manager, or deployment platform unless the repository establishes one.

## Working guidelines

- Inspect the repository and read its documentation before editing.
- Keep implementation aligned with the user's stated goal and current scope.
- Preserve user changes and avoid unrelated modifications.
- Prefer focused, readable changes with clear boundaries.
- Follow established project conventions once they exist.
- Add or update tests for behavior changes.
- Run relevant verification before claiming completion.
- Keep `README.md` current when setup, commands, architecture, or workflows change.
- Never commit secrets, credentials, generated artifacts, or local environment files.

## Git workflow

- Review the working tree before making changes.
- Use the `codex/` prefix when creating branches unless the user requests another name.
- Do not rewrite history or discard changes without explicit authorization.
- Do not commit or push unless the user asks.

## Communication

- Surface assumptions when information is missing.
- Report blockers with concrete evidence.
- Summarize files changed and checks run when handing off work.
