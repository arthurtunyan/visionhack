# Claude Project Instructions

## Project context

VisionHack is in its initial setup phase. Do not assume a framework, language, package manager, or deployment platform unless the repository establishes one.

## Working guidelines

- Read the repository structure and existing documentation before making changes.
- Follow the user's request and keep changes limited to the requested scope.
- Preserve existing work and avoid unrelated refactors.
- Prefer simple, maintainable solutions over premature abstractions.
- Match established code style and conventions once they exist.
- Add or update tests when changing behavior.
- Run relevant checks before reporting work as complete.
- Update `README.md` when setup, commands, architecture, or workflows change.
- Never commit secrets, credentials, generated artifacts, or local environment files.

## Communication

- State important assumptions when repository context is incomplete.
- Explain blockers clearly and include the evidence needed to resolve them.
- Summarize changed files and verification results when handing off work.
